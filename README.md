Entry for the [Six Words, One Story](https://make.fun/c/u-deranalabs-six-words-one-story-f982e410) competition on [make.fun](https://make.fun).

## The story

> He returned home. Nobody remembered him.

## How it works

`main.ts` writes the six-word story to `/output/entry.txt`. It validates
before writing: exactly six words, 1–60 characters of UTF-8 text, matching
the competition gate. Run it with Node 22 or later:

```sh
node main.ts
cat /output/entry.txt
```
